# Getting started — 30 October 2026

Use Python 3.11 and Node.js 20+. Run `python3 scripts/dev.py setup --with-vision`, provision separately authorized damage/retrieval assets, then run `python3 scripts/provision_evidence_models.py` and `python3 scripts/dev.py doctor` before `python3 scripts/dev.py start`. Local ports are 5183/8010/8011; credentials are generated under ignored `var/`. Existing dependency symlinks are not portable. See the complete documentation for legacy OSNet conversion/archive extraction, and FULL_STACK.md for isolated Docker verification.
