# Narrated walkthrough artifacts

The local working checkout contains `IntelliClaim_Narrated_Walkthrough.mp4` (102.6 seconds), captured browser-state images and render intermediates. It is an edited walkthrough with synthesized macOS Aman narration, not a continuous recording or a cloned user voice.

This public source includes the narration transcript, SRT captions, artifact manifest and `scripts/render_narrated_demo.py`. The MP4 and screenshots contain separately sourced research/demo imagery and remain local pending redistribution clearance. Rendering requires actual captured browser images under `submission/demo_frames`, the macOS `say` command, Pillow and `imageio-ffmpeg`.
